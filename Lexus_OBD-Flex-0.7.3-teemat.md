# Lexus OBD Flex 0.7.3 · Teemat

## Teeman vaihtaminen

1. Avaa **Yhteys**.
2. Avaa **Sovelluksen teema** -kortti.
3. Valitse teema luettelosta.

Muutos näkyy heti. Valinta säilyy sovelluksen sulkemisen, puhelimen
uudelleenkäynnistyksen ja Flex-päivityksen yli.

## Vaihtoehdot

| Teema | Käyttötarkoitus |
| --- | --- |
| Järjestelmä | Seuraa automaattisesti Androidin tummaa tai vaaleaa tilaa. |
| Lexus Dark | Flexin alkuperäinen tumma vihreä teema. |
| Pearl Light | Vaalea helmiäissävyinen teema valoisaan ympäristöön. |
| OLED Black | Puhdas musta tausta etenkin OLED-näytölle ja hämärään. |
| Hybrid Blue | Tumma sininen CT 200h -henkinen teema. |
| F Sport Red | Grafiitinharmaa ulkoasu punaisella korostuksella. |
| Korkea kontrasti | Musta, valkoinen ja keltainen mahdollisimman selkeään luettavuuteen. |

## Miten värit toimivat

Teeman korostusväri näkyy esimerkiksi pääpainikkeissa, aktiivisessa
välilehdessä ja kuvaajissa. Tilavärien merkitys ei muutu:

- vihreä = onnistui tai kunnossa
- keltainen = varoitus tai keskeneräinen
- punainen = virhe tai pysäyttävä havainto
- sininen = tieto tai valmis mittaustulos

Live-datan, Tehotestin ja tallennettujen ajojen kuvaajat päivittyvät heti
teeman vaihtuessa. Jokaisen paletin perustekstin, himmeän tekstin ja
pääpainikkeen kontrasti tarkistetaan automaattisesti WCAG AA -tasoa vasten.

Teemavalinta tallennetaan vain paikallisesti. Se ei lisää sovellukselle uusia
Android-oikeuksia, verkkoyhteyttä tai auton ohjainlaitteille lähetettäviä
komentoja.
